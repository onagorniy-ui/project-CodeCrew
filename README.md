# Personal Assistant Bot (Final Project)

Консольний бот-помічник для управління контактами та нотатками.

## 🚀 Функціонал
- **Адресна книга**: зберігання контактів (ім'я, телефони, email, адреса, день народження).
- **Нотатки**: створення нотаток з тегами та можливістю пошуку/редагування.
- **Нагадування**: відстеження днів народження на найближчі дні.
- **Кольоровий інтерфейс**: підтримка бібліотеки `colorama`.

## 📁 Структура проєкту (Модульність)
Проєкт розбито на окремі модулі для зручної паралельної командної розробки:

- **`main.py`** — головний цикл програми (`while True`), парсинг команд та точка входу.
- **`models.py`** — класи даних (`Record`, `AddressBook`, `Note`, `NoteBook`, `Field` тощо).
- **`handlers.py`** — функції-обробники команд та декоратор помилок `@input_error`.
- **`storage.py`** — збереження та завантаження даних через `pickle` (`save_data`, `load_data`).
- **`requirements.txt`** — список залежностей (`colorama`).
- **`.gitignore`** — конфігурація виключень для Git.

## 🛠️ Встановлення та запуск

1. Склонуйте репозиторій:
   ```bash
   git clone https://github.com/onagorniy-ui/project-python-2.git
   cd project-python-2
   ```

2. Створіть та активуйте віртуальне середовище:
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # На macOS/Linux
   # .venv\Scripts\activate   # На Windows
   ```

3. Встановити залежності:
   ```bash
   pip install -r requirements.txt
   ```

4. Запустити бота:
   ```bash
   python main.py
   ```

## 👥 Командна розробка (Git Workflow)
- **Ніколи не комітьте напряму в `main`**.
- Створюйте окрему гілку під кожне завдання:
  ```bash
  git checkout -b feature/назва-фічі
  ```
- Команда розподіляє роботу по файлах (наприклад, один розробник розширює `models.py`, інший додає обробники у `handlers.py`).
- Після завершення відкривайте **Pull Request (PR)** на GitHub для перевірки.
