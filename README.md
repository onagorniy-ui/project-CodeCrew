# Фінальний командний проєкт — Бот-помічник

Консольний бот-помічник для керування контактами та нотатками. Робимо як командний фінальний проєкт.

## Що вміє наш бот (і що плануємо доробити)
- Зберігати контакти: ім'я, номери телефонів, пошта, день народження, адреса.
- Нагадувати про дні народження наперед (за вказану кількість днів).
- Робити валідацію: перевіряти правильність телефону (рівно 10 цифр) та email.
- Шукати, змінювати та видаляти контакти.
- Створювати нотатки, додавати до них теги, шукати і сортувати за тегами.
- Зберігати всі дані у файл на диску, щоб нічого не губилося після виходу з програми.
- Вгадувати команду, якщо користувач зробив невелику помилку в написанні.

## Структура файлів проєкту
Щоб зручно писати код усім разом і не мати конфліктів у гіті, ми розділили проєкт на такі файли:

- `main.py` — головний файл запуску програми, тут крутиться цикл взаємодії з користувачем.
- `classes.py` — тут описані всі наші класи (для контактів, полів та нотаток).
- `commands.py` — функції-обробники команд бота та загальний декоратор для помилок (input_error).
- `storage.py` — функції для збереження та завантаження даних через pickle у файл `data.pkl`.
- `requirements.txt` — список зовнішніх бібліотек (colorama).

## Як запустити проєкт

1. Клонуємо репозиторій:
```bash
git clone https://github.com/onagorniy-ui/project-CodeCrew.git
cd project-CodeCrew
```

2. Створюємо та активуємо віртуальне середовище:
```bash
python3 -m venv .venv
source .venv/bin/activate  # для macOS / Linux
# .venv\Scripts\activate   # для Windows
```

3. Встановлюємо залежності:
```bash
pip install -r requirements.txt
```

4. Запускаємо бота:
```bash
python main.py
```

## Як ми працюємо в команді з Git
- У гілку `main` напряму нічого не комітимо і не пушимо.
- Перед початком роботи обов'язково оновлюємо свій main: `git pull origin main`.
- Під кожну нову задачу створюємо окрему гілку:
  `git checkout -b feature/назва-задачі`
- Після написання та перевірки коду робимо коміт і пушимо у свою гілку:
  `git add .`
  `git commit -m "опис того що зробили"`
  `git push -u origin feature/назва-задачі`
- На GitHub створюємо Pull Request, щоб злити зміни в `main`.
